# 循练 H5 体验原型

这是「循练」AI 健身管理产品的**纯前端、虚构数据交互演示**，规则参考 Skill V1.3.4。没有 AI 后台，不采集真实健康资料，不提供可以直接跟练的训练处方。当前 GitHub Pages 线上站点仍由 `main` 发布。

## V0.2A 开发预览（仅在 feature/v0.2a-mobile-time-budget）

- 7题访谈明确提示：点选后自动进入下一题，可返回修改。
- 手机操作区域优化：选项、日志按钮及进度导航改善可触达性。
- 在计划页显示60分钟或40分钟**示意时间预算**，明确分开热身、主要动作执行、组间休息、器械切换及结束整理；各项总和必须恰好等于单次时长。
- 每周3天的训练卡采用原生折叠，默认展开第1天，减少长页面滚动。
- 访谈—计划—记录—复盘四阶段可视化导航。
- 不满足演示条件时，继续维持已有的安全阻断、信息不足或器械条件受限提示，不生成完整训练卡。

### 当前验证

已通过静态语法编译与8种虚构场景的逻辑回放：60分钟/40分钟READY、明显高血压/关节不适BLOCKED、无器械/器械未购买PROVISIONAL、时长未知/明显疲劳NEED_ONE_ANSWER。

**尚未完成：** 真人教练审核、真实训练安全审查、手机实机视觉验收和V0.2B日志驱动自动调整。因此不可作为真人训练指南或商业化医疗运动产品。
